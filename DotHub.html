Discover public Linux dotfile repositories from GitHub. Findings stay in a local review list until you mark them. This page only collects repository metadata; it never downloads repositories or runs their scripts.

How this file works
It calls GitHub’s public REST API from your browser and stores results in this browser’s local storage. Open it in a browser while online. GitHub supports cross-origin browser requests; rate limits or network restrictions can still prevent a scan. GitHub CORS docs ↗
Reddit and other sources

Reddit is not fetched from this standalone file. Reddit requires an authorized API integration, and putting its access token in a browser file would expose it. Other sites need a public RSS/Atom feed and server-side robots checks; this file has no backend for that. Use the full DotHub Python app for review-queue collection and moderation.
